# kakeibo

自前の家計簿管理システム。
Zaimに自動登録された支出データをCSVエクスポートし、インポート・集計・管理します。

## 概要
Zaimから取得したデータをGoogleスプレッドシート上で管理し、集計や可視化を行うためのGoogle Apps Scriptプロジェクトです。

## 主な機能
- **データインポート**: ZaimからエクスポートされたCSVデータの取り込み。
- **カテゴリ管理**: 支出カテゴリの自動振り分けや集計。
- **Webアプリ連携**: WebアプリUIを介したデータの確認や操作。
  - 日付入力時の曜日表示対応。
- **自動集計**: スプレッドシート関数やスクリプトによる自動集計。

## 技術スタック
- Google Apps Script (GAS)
- Google Spreadsheet
- clasp (管理ツール)

## 開発・デプロイ
`clasp`を使用して開発を行っています。
