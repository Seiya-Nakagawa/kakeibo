## 1. 概要

対応Issue: [#25](https://github.com/Seiya-Nakagawa/kakeibo/issues/25)

月次収支・カテゴリ別支出・予算対比・各種グラフを表示するダッシュボード（画面2）を実装する。
`HomeView`（暫定のログイン後遷移先）を廃止し、ダッシュボードをルートパスに割り当てる。
対応する設計書: [基本設計書3.3節](../02.設計/基本設計書.md#33-集計要件-47)、
[5.3.1節](../02.設計/基本設計書.md#531-ダッシュボード2)、
[2.2節](../02.設計/基本設計書.md#22-採用ライブラリ)（グラフ描画ライブラリ）

## 3. 手順

### 3.1. Chart.jsをvendor配置する

CDNへの実行時依存を避けるため、Chart.jsをリポジトリ内に配置する（自己完結・オフライン
動作可能にするため）。

```bash
mkdir -p webapp/kakeibo/static/kakeibo/vendor
curl -sL -o webapp/kakeibo/static/kakeibo/vendor/chart.umd.min.js \
  https://cdn.jsdelivr.net/npm/chart.js@4.5.0/dist/chart.umd.min.js
```

- Django Appの`static/`配下（`AppDirectoriesFinder`）に配置することで、
  `{% static %}`タグから追加設定なしに参照できる

### 3.2. 集計ロジックを実装する

`webapp/kakeibo/aggregation.py`を新規作成する。

```python
"""月次集計ロジック（基本設計書3.3節）。"""

from dataclasses import dataclass
from datetime import date, timedelta

from django.db.models import Q, Sum

from kakeibo.models import Account, BalanceRecord, Category, FixedCost, FixedIncome, Transaction


def month_start(target: date) -> date:
    return target.replace(day=1)


def add_months(target: date, delta: int) -> date:
    month_index = target.month - 1 + delta
    year = target.year + month_index // 12
    month = month_index % 12 + 1
    return date(year, month, 1)


def month_end(target: date) -> date:
    return add_months(month_start(target), 1) - timedelta(days=1)


def _covers_month(start: date) -> Q:
    """固定費・固定収入の適用期間（start_month〜end_month）が対象月を含むかの条件。"""
    return Q(end_month__isnull=True) | Q(end_month__gte=start)


def _sum(queryset, field="amount") -> int:
    return queryset.aggregate(total=Sum(field))["total"] or 0


def variable_expense_total(target_month: date) -> int:
    """変動費実績（基本設計書3.3節）。"""
    start, end = month_start(target_month), month_end(target_month)
    return _sum(
        Transaction.objects.filter(
            transaction_type=Transaction.TransactionType.EXPENSE,
            transaction_date__range=(start, end),
            is_deleted=False,
            is_excluded_from_aggregation=False,
        )
    )


def fixed_expense_total(target_month: date) -> int:
    """固定費実績（適用期間に対象月を含む固定費の合計）。"""
    start = month_start(target_month)
    queryset = FixedCost.objects.filter(start_month__lte=start).filter(_covers_month(start))
    return _sum(queryset)


def income_total(target_month: date) -> int:
    """収入実績（基本設計書3.3節）。"""
    start, end = month_start(target_month), month_end(target_month)
    variable = _sum(
        Transaction.objects.filter(
            transaction_type=Transaction.TransactionType.INCOME,
            transaction_date__range=(start, end),
            is_deleted=False,
            is_excluded_from_aggregation=False,
        )
    )
    fixed = _sum(FixedIncome.objects.filter(start_month__lte=start).filter(_covers_month(start)))
    return variable + fixed


@dataclass(frozen=True)
class CategorySummary:
    category: Category
    actual: int
    budget: int | None
    diff: int | None


def category_breakdown(target_month: date) -> list[CategorySummary]:
    """カテゴリ別支出実績・予算・差額（基本設計書3.3節、5.3.1節）。

    is_aggregated=FALSEのカテゴリは集計・予算対比の対象外とする。
    """
    start, end = month_start(target_month), month_end(target_month)
    summaries = []
    categories = Category.objects.filter(
        category_type=Category.CategoryType.EXPENSE, is_aggregated=True
    ).order_by("display_order")
    for category in categories:
        variable = _sum(
            Transaction.objects.filter(
                category=category,
                transaction_date__range=(start, end),
                is_deleted=False,
                is_excluded_from_aggregation=False,
            )
        )
        fixed = _sum(
            FixedCost.objects.filter(category=category, start_month__lte=start).filter(
                _covers_month(start)
            )
        )
        actual = variable + fixed
        budget = category.monthly_budget
        diff = (budget - actual) if budget is not None else None
        summaries.append(CategorySummary(category=category, actual=actual, budget=budget, diff=diff))
    return summaries


@dataclass(frozen=True)
class AccountBalance:
    account: Account
    latest_record: BalanceRecord | None


def account_balances(as_of: date) -> list[AccountBalance]:
    """口座ごとの最新残高記録（基本設計書5.3.5節: 口座一覧）。"""
    results = []
    for account in Account.objects.filter(is_active=True).order_by("display_order"):
        latest = (
            BalanceRecord.objects.filter(account=account, recorded_date__lte=as_of)
            .order_by("-recorded_date")
            .first()
        )
        results.append(AccountBalance(account=account, latest_record=latest))
    return results


def total_assets_as_of(as_of: date) -> int:
    """総資産（有効な口座ごとのbalance_recordsの最新記録を合算、基本設計書3.3節）。"""
    return sum(ab.latest_record.balance for ab in account_balances(as_of) if ab.latest_record)


def assets_by_account_type(as_of: date) -> dict:
    """口座種別ごとの資産内訳（基本設計書5.3.5節: サマリー）。"""
    totals: dict = {}
    for ab in account_balances(as_of):
        if not ab.latest_record:
            continue
        label = ab.account.get_account_type_display()
        totals[label] = totals.get(label, 0) + ab.latest_record.balance
    return totals


@dataclass(frozen=True)
class MonthlyBalance:
    month: date
    income: int
    expense: int
    diff: int


def monthly_balance_trend(target_month: date, months: int = 12) -> list[MonthlyBalance]:
    """月次収支推移（直近Nヶ月、基本設計書5.3.1節）。"""
    results = []
    for offset in range(months - 1, -1, -1):
        month = add_months(month_start(target_month), -offset)
        expense = variable_expense_total(month) + fixed_expense_total(month)
        income = income_total(month)
        results.append(MonthlyBalance(month=month, income=income, expense=expense, diff=income - expense))
    return results


def asset_trend(target_month: date, months: int = 12) -> list[tuple]:
    """総資産推移（直近Nヶ月の月末時点、基本設計書5.3.1節・5.3.5節）。"""
    results = []
    for offset in range(months - 1, -1, -1):
        month = add_months(month_start(target_month), -offset)
        results.append((month, total_assets_as_of(month_end(month))))
    return results


def unclassified_transaction_count() -> int:
    return Transaction.objects.filter(
        category__isnull=True,
        transaction_type=Transaction.TransactionType.EXPENSE,
        is_deleted=False,
    ).count()
```

- `account_balances`・`total_assets_as_of`・`assets_by_account_type`は、次のIssue
  （#26 資産残高画面実装）でも共用する

### 3.3. ダッシュボードビューを実装する

`webapp/kakeibo/views.py`の`HomeView`を削除し、代わりに`DashboardView`
（`TemplateView`）を実装する。`?month=YYYY-MM`クエリパラメータで対象月を指定できるように
し（省略時は当月）、3.2の集計関数の結果をテンプレート用にコンテキストへ詰める
（グラフ用データは`{{ ... |json_script:"..." }}`でJSON化する前提のリスト形式で渡す）。

### 3.4. URLをダッシュボードへ置き換える

`webapp/config/urls.py`のルートパス（`""`）を`HomeView`から`DashboardView`へ、
URL名を`home`から`dashboard`へ変更する。`webapp/config/settings/base.py`の
`LOGIN_REDIRECT_URL`も`"dashboard"`に変更する。不要になった
`webapp/kakeibo/templates/kakeibo/home.html`を削除する。

### 3.5. テンプレートを作成する

`webapp/kakeibo/templates/kakeibo/dashboard.html`を新規作成する（`base.html`を継承）。

- 対象月選択（`<input type="month">`、変更時に自動サブミット）
- サマリー（収入・支出・収支差額）、カテゴリ別支出テーブル（予算超過は赤字強調）
- 4種のグラフ（月次支出推移・当月カテゴリ別構成比・月次収支推移・総資産推移）を、
  `{% load static %}`で読み込んだChart.jsと`json_script`で埋め込んだデータで描画する
- 未分類取引がある場合、件数と未分類取引一覧へのリンクを表示する

### 3.6. 静的ファイル配信（WhiteNoise）を設定する

Django Admin・Chart.jsの静的ファイルを本番（gunicorn、`DEBUG=False`）でも配信できるよう、
`webapp/pyproject.toml`に`whitenoise>=6.11.0`を追加し、
`webapp/config/settings/base.py`に以下を設定する。

```python
MIDDLEWARE = [
    "django.middleware.security.SecurityMiddleware",
    # 静的ファイル（Admin/Chart.js等）をgunicornから直接配信する（本番、7.4節: デプロイの自動化）。
    "whitenoise.middleware.WhiteNoiseMiddleware",
    "django.contrib.sessions.middleware.SessionMiddleware",
    ...
]

STATIC_ROOT = BASE_DIR / "staticfiles"

STORAGES = {
    "default": {
        "BACKEND": "django.core.files.storage.FileSystemStorage",
    },
    "staticfiles": {
        "BACKEND": "whitenoise.storage.CompressedStaticFilesStorage",
    },
}
```

`webapp/.gitignore`相当として、リポジトリルートの`.gitignore`に
`webapp/staticfiles/`（`collectstatic`の出力先）を追加する。

### 3.7. Dockerfileにcollectstaticを追加する

`webapp/Dockerfile`のruntimeステージで、`USER appuser`の前に`collectstatic`を実行する。
`collectstatic`はDBに接続しないが、`config.settings.production`の読み込み時に
必須の環境変数（`SECRET_KEY`等）が必要なため、ビルド専用のダミー値を設定する。

```dockerfile
ENV PATH="/app/.venv/bin:${PATH}" \
    PYTHONUNBUFFERED=1 \
    PYTHONDONTWRITEBYTECODE=1 \
    DJANGO_SETTINGS_MODULE=config.settings.production \
    SECRET_KEY=collectstatic-build-only \
    DB_NAME=collectstatic \
    DB_USER=collectstatic \
    DB_PASSWORD=collectstatic \
    GOOGLE_OAUTH_CLIENT_ID=collectstatic \
    GOOGLE_OAUTH_CLIENT_SECRET=collectstatic \
    ALLOWED_HOSTS=localhost

RUN python manage.py collectstatic --noinput

USER appuser
```
