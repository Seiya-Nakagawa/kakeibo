## 1. 概要

対応Issue: [#16](https://github.com/Seiya-Nakagawa/kakeibo/issues/16)

未分類取引へのカテゴリ割当時、店舗名からどの部分をキーワードとして抽出し`store_rules`へ
自動登録するかの規則を決定する。実データ（決済通知メールの実際の店舗名表記）を確認しながら
決定する想定だったが、実データが確認できる状態（メール取込の実運用）に至っていないため、
店舗名（正規化済み）全体をキーワードとする保守的な規則を暫定的に採用する。
対応する設計書: [基本設計書3.2節](../02.設計/基本設計書.md#32-カテゴリ判定要件-42)

## 3. 手順

### 3.1. カテゴリ判定・自動学習ロジックを実装する

`webapp/kakeibo/categorization.py` を新規作成する。

```python
"""カテゴリ判定・自動学習ロジック（基本設計書3.2節）。"""

import unicodedata

from django.db.models import Max

from kakeibo.models import Category, StoreRule


def normalize_store_name(value: str) -> str:
    """店舗名・キーワードの正規化（全角半角・大文字小文字の統一）。"""
    return unicodedata.normalize("NFKC", value).upper().strip()


def match_category(counterpart: str) -> Category | None:
    """店舗ルールに基づきカテゴリを判定する。一致しない場合はNone（未分類）を返す。"""
    normalized_counterpart = normalize_store_name(counterpart)
    for rule in StoreRule.objects.select_related("category").order_by("priority"):
        if normalize_store_name(rule.keyword) in normalized_counterpart:
            return rule.category
    return None


def extract_keyword(counterpart: str) -> str:
    """未分類取引へのカテゴリ割当時、店舗名から自動学習用キーワードを抽出する。

    実データ（決済通知メールの実際の店舗名表記）が確認できていないため、
    店舗名（正規化済み）全体をキーワードとして採用する保守的な規則とする
    （Issue #16、実データ確認後に見直す可能性がある）。
    """
    return normalize_store_name(counterpart)


def register_learned_rule(category: Category, counterpart: str) -> StoreRule:
    """未分類取引へのカテゴリ割当時、店舗ルールへ自動登録する（要件4.2.6）。"""
    keyword = extract_keyword(counterpart)
    next_priority = (StoreRule.objects.aggregate(Max("priority"))["priority__max"] or 0) + 1
    rule, _ = StoreRule.objects.update_or_create(
        keyword=keyword,
        defaults={
            "category": category,
            "is_auto_generated": True,
            "priority": next_priority,
        },
    )
    return rule
```

- `normalize_store_name`: `unicodedata.normalize("NFKC", ...)`で全角半角を統一し、
  `.upper()`で大文字小文字を統一する（基本設計書3.2節 手順1）
- `match_category`: `priority`昇順で最初に部分一致したルールのカテゴリを返す
  （基本設計書3.2節 手順2〜3）
- `register_learned_rule`: 既存の最大`priority`の次の値を付与し、末尾に追加する
  （自動生成ルールは手動定義ルールより後に評価されるようにする）。同一キーワードで
  再割当された場合は`update_or_create`により上書きする

### 3.2. 設計書のmark箇所を確定記述に更新する

[基本設計書3.2節](../02.設計/基本設計書.md#32-カテゴリ判定要件-42)の
`<mark>店舗名からのキーワード抽出規則は未確定</mark>`箇所を、3.1で決定した規則
（店舗名全体をキーワードとする）に基づく確定記述へ更新する。

### 3.3. テストを追加する

`webapp/kakeibo/tests/test_categorization.py`に以下を追加する。

- 全角・大文字小文字が異なっていても正規化により一致すること
- 一致するルールがない場合は`None`（未分類）を返すこと
- `priority`の昇順で最初に一致したルールが採用されること
- `extract_keyword`が正規化済みの店舗名全体を返すこと
- `register_learned_rule`が自動生成ルールを作成し、既存の最大`priority`の次の値を
  付与すること。同一店舗への再割当が新規作成ではなく更新になること
