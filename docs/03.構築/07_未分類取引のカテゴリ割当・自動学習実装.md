## 1. 概要

対応Issue: [#23](https://github.com/Seiya-Nakagawa/kakeibo/issues/23)

未分類取引一覧画面と、カテゴリ割当時の店舗ルール自動学習を実装する。
対応する設計書: [基本設計書3.2節](../02.設計/基本設計書.md#32-カテゴリ判定要件-42)、
[5.3.4節](../02.設計/基本設計書.md#534-未分類取引一覧5)

## 2. 前提条件

- [06_カテゴリ自動学習キーワード抽出規則決定.md](06_カテゴリ自動学習キーワード抽出規則決定.md)
  の完了により`kakeibo.categorization`が利用可能であること

## 3. 手順

### 3.1. カテゴリ割当フォームを追加する

`webapp/kakeibo/forms.py` に以下を追加する。

```python
class CategoryAssignForm(forms.Form):
    """画面5 未分類取引一覧: カテゴリ選択・割当（基本設計書5.3.4節）。"""

    category = forms.ModelChoiceField(
        queryset=Category.objects.filter(category_type=Category.CategoryType.EXPENSE)
    )
```

### 3.2. ビューを実装する

`webapp/kakeibo/views.py` に以下を追加する。

- `UnclassifiedTransactionListView`（`ListView`）: `is_deleted=False`、
  `category__isnull=True`、`transaction_type=expense`（未分類は支出のみ発生する、
  基本設計書4.2.10節）で絞り込む
- `AssignCategoryView`（`View`）: `CategoryAssignForm`のPOSTを受け、対象取引へ
  カテゴリを設定したうえで`categorization.register_learned_rule`を呼び出す

### 3.3. URLを実体に置き換える

`webapp/config/urls.py`の`unclassified-transaction-list`（05でHomeViewへ暫定割当していた
URL名）を`UnclassifiedTransactionListView`へ置き換え、カテゴリ割当用のURLを追加する。

```python
path(
    "transactions/unclassified/",
    views.UnclassifiedTransactionListView.as_view(),
    name="unclassified-transaction-list",
),
path(
    "transactions/<int:pk>/assign-category/",
    views.AssignCategoryView.as_view(),
    name="transaction-assign-category",
),
```

### 3.4. テンプレートを作成する

`webapp/kakeibo/templates/kakeibo/unclassified_transaction_list.html`を新規作成する
（`base.html`を継承。日付・店舗名・金額・決済手段の一覧と、行ごとのカテゴリ選択・割当フォーム）。

### 3.5. テストを追加する

`webapp/kakeibo/tests/test_unclassified.py`に以下を追加する。

- 一覧が未分類（`category`が`NULL`）かつ支出の取引のみを表示すること
- カテゴリ割当により取引の`category`が更新され、`store_rules`へ自動生成ルールが
  登録されること
- 自動学習後、同一店舗名の取引が`match_category`で自動分類されること
