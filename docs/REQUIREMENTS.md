# 要件定義書（現行 GAS 版）

> **注記**: 本ドキュメントは現在稼働中の GAS + Google スプレッドシート版システムの記録である。
> OCI 移行後の新システムは [`01.要件定義/要件定義書.md`](01.要件定義/要件定義書.md) および
> [`02.設計/基本設計書.md`](02.設計/基本設計書.md) を参照すること。
> 移行完了後に本ドキュメントは廃止する。

## 1. プロジェクト概要

決済サービスの利用通知メールを自動解析し、Google Sheets へ直接登録する個人家計簿システム。
Zaim を介さず、メール → Google Sheets の一貫したフローで支出を管理する。

## 2. 対象範囲

- **入力**: Gmail に着信する決済サービスの利用通知メール、および月次固定費
- **出力**: Google Sheets 家計簿（生データ・集計・可視化）
- **対応メールソース**:
  - 楽天ペイ（アプリ決済）
  - 楽天ペイ（オンライン決済）
  - 楽天カード
- **固定費**: 住宅ローン返済（金額固定、口座連携不可のため手動定義）
- **対象外**: 収入管理、資産残高管理（Zaim 側で引き続き管理）

## 3. システム構成

- **プラットフォーム**: Google Apps Script (GAS)
- **ストレージ**: Google Sheets（家計簿本体）
- **AI**: Gemini API 無料枠（カテゴリ自動判定のフォールバック）

```text
Gmail（決済通知メール）
    ↓ GAS（時間トリガー）
メールパース
    ↓
カテゴリ判定（ルールマスタ → 未判定時 Gemini API）
    ↓
Google Sheets（生データシート）書込
    ↓
月次集計シート・可視化シート 自動更新
```

## 4. 機能要件

### 4.1. メール取得機能

- GAS の時間トリガー（日次）で自動実行する
- 設定した日数前〜現在を対象期間とする
- 送信元・件名でフィルタリングし、対応サービスのメールのみ取得する
- 取得済みメールを再処理しないよう、処理済みメッセージ ID を管理する

### 4.2. メールパース機能

対応サービスごとに以下の情報を抽出する。

| 項目 | 内容 |
| ---- | ---- |
| 日付 | 利用日（`YYYY-MM-DD`） |
| 金額 | 支出額（円、整数） |
| 店舗名 | 利用店舗またはサービス名 |
| 決済手段 | 楽天ペイ / 楽天カード など |

### 4.3. カテゴリ判定機能

2段階でカテゴリを判定する。

1. **ルール判定（優先）**: 店舗名→カテゴリのマスタシートを参照し、一致したカテゴリを適用する
2. **LLM 判定（フォールバック）**: マスタに存在しない店舗名は Gemini API に問い合わせてカテゴリを推論する

**LLM 判定結果の視覚的区別**:

- LLM で判定したカテゴリのセルには背景色（黄色）を付与し、後でユーザーが確認・修正できるようにする
- ユーザーがカテゴリを手動修正したら、背景色を除去する（未実装でも可）

**カテゴリ体系**:

- Zaim のカテゴリを使用せず、独自カテゴリを Google Sheets のマスタシートで定義する

### 4.4. Google Sheets 書込機能

- 生データシートに1行1レコードで追記する
- 書込フォーマット（列順）:

  | 列 | 内容 |
  | -- | ---- |
  | A | 日付 |
  | B | 金額（支出） |
  | C | 店舗名 |
  | D | 決済手段 |
  | E | カテゴリ |
  | F | メモ |
  | G | 登録方法（auto / fixed） |

### 4.5. 重複排除機能

- (日付 + 金額 + 店舗名 + 決済手段) を組み合わせたハッシュで重複判定する
- 同一ハッシュのレコードが既存の場合、スキップして二重登録を防ぐ

### 4.6. 固定費自動登録機能

- 月次トリガー（月初など任意日）で実行する
- 固定費マスタシートに定義した項目を生データシートへ自動登録する
- 住宅ローンを当初の登録対象とし、今後マスタ追加で拡張可能な設計とする

### 4.7. 手動入力 Web 画面

- GAS の Web アプリ機能（HtmlService）でブラウザからアクセスできる入力フォームを提供する
- メールで自動取得できない支出（現金払い、口座引落等）を手動登録する
- 入力項目:
  - 日付（必須）
  - 金額（必須）
  - 店舗名 / 支払先（必須）
  - カテゴリ（マスタから選択）
  - 決済手段（選択）
  - メモ（任意）
- 送信後、生データシートに追記される（登録方法列は `manual` とする）
- 直近の登録一覧を画面下部に表示し、誤入力を確認・削除できるようにする

### 4.8. 月次集計・可視化機能

- 月次集計シートにカテゴリ別・月別の支出合計を自動計算する
- 以下のグラフを Sheets のグラフ機能で表示する:
  - 月次支出推移（棒グラフまたは折れ線グラフ）
  - カテゴリ別支出比率（円グラフ）

## 5. スプレッドシート構成

| シート名 | 用途 |
| -------- | ---- |
| 生データ | 全取引レコード（GAS が書き込む） |
| 店舗ルール | 店舗名→カテゴリのマッピングルール |
| 固定費マスタ | 住宅ローン等の固定費定義 |
| 月次集計 | カテゴリ別・月別の集計（自動更新）。A〜C列がカテゴリマスタを兼ねる |

## 6. 非機能要件

- **コスト**: 全て無料枠で運用する（GAS 無料枠、Gemini API 無料枠）
- **セキュリティ**: API キー等の機密情報はスクリプトプロパティで管理し、コード内に直接記述しない
- **拡張性**: 対応メールソースを設定追加だけで拡張できる設計とする
- **パフォーマンス**: 外部 API のレート制限を遵守し、処理間に適切な待機時間を設ける
